# FactBot 2.0: профессор-рассказчик

Каждый запуск GitHub Actions берёт следующий сценарий из `queue/`, озвучивает его мужским голосом (Piper),
подбирает картинки (NASA / Pixabay), анимирует профессора в Remotion и присылает готовый ролик в Telegram.

## Файлы
- `src/Scene.jsx`: вся анимация (профессор, карточки, субтитры, плашки)
- `run.py`: сценарий → озвучка → картинки → рендер → Telegram
- `queue/*.json`: очередь сценариев
- `.github/workflows/video.yml`: расписание и установка

## Секреты (Settings → Secrets and variables → Actions)
`PIXABAY_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`

## Формат сценария (история)
```json
{
  "title": "Заголовок",
  "intro": {"title": "СТРОКА 1|*КЛЮЧЕВОЕ*", "text": "Что говорит профессор в начале"},
  "scenes": [
    {"text": "Фраза рассказчика, *слово* = красное", "prompt": "english scene description",
     "tag": "1932 · АВСТРАЛИЯ", "alert": "КРАСНАЯ ПЛАШКА", "cam": "in"}
  ],
  "punch": {"big": "ФИНАЛЬНАЯ|*ФРАЗА*", "text": "Что звучит на чёрном экране"},
  "outro": {"text": "Что говорит профессор в конце"},
  "source": "Источник", "description": "Описание", "hashtags": ["факты"]
}
```
`cam`: in, out, left, right, up, shake. Картинки сцен рисует нейросеть (Pollinations, запасной Cloudflare Workers AI через секреты `CF_ACCOUNT_ID` и `CF_API_TOKEN`).

## Голос
Переменные репозитория (Settings → Secrets and variables → Actions → Variables): `VOICE` (dmitri/denis/ruslan), `VOICE_SPEED`, `VOICE_PITCH`. Тест голосов: Run workflow → mode = voices.

## Расписание
`cron` в `video.yml`, время в UTC (Москва = UTC+3).

## v14: первая секунда
- Хук открывается сверхкрупным планом лица первого персонажа (кадры 0–4), к ~0.6 с камера отъезжает на общий план.
  `hook.hookFocus`: номер актёра для крупного плана (по умолчанию первый живой); `hook.open: "wide"` выключает приём.
- Первая фраза субтитров видна сразу на 0-м кадре; субтитры подняты выше нижней зоны интерфейса TikTok.
- Персонажи не моргают в первые 20 кадров сцены (кадр 0 = превью в ленте).
- Хук контрастнее и насыщеннее вместо «засветки».
- Если хук длиннее 3.5 с, бот предупреждает в Telegram.

## v15: стиль «кибер-нуар» (истории на «ты»)
Включается полем истории `"style": "noir"`. Профессора нет, в конце — экран выбора.
- `hud_labels`: подписи шкалы, по умолчанию `["КОГДА", "НА КОНУ", "ШАНС ВЫКРУТИТЬСЯ"]`.
- `hud` в хуке/сцене: `{"time": "02:47", "balance": "10 BTC", "chance": 80}` — значения плавно перетекают, шанс тает.
- `ui` в хуке/сцене: карточка или список карточек — `notify`, `wallet`, `chat`, `card`, `doc`, `table`, `timer`, `alert`, `chain`, `call`, `form`.
  Если в сцене есть персонажи, интерфейс показывается со второй половины (`uiAt`, по умолчанию 0.45); `notify` — поверх сцены.
- Главный герой: персонаж с `"you": true` (метка «ТЫ»), `look.hood: true` — капюшон, `look.rim` — цвет контурного света, `held: "phone"`, `anim: "phone"`.
- `choice`: `{"text": "...", "question": "ТВОЙ ХОД", "options": ["...", "..."], "next": true}` — экран выбора; `next` — «продолжение в следующем ролике».
- `part`: 1 или 2 — подпись на обложке. Части идут в очереди подряд.
- `voice` — свой голос SpeechKit для истории, `voice_speed` — темп (в нуаре по умолчанию 1.08, хук ещё ×1.1).
- Новые фоны: `noir_room`, `noir_city`.
